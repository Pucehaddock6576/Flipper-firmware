## 📝 Guidelines for Contributing Screenshots

### Requirements
- **Resolution**: 1280x720 minimum
- **Format**: PNG for screenshots, MP4 for videos
- **Quality**: High quality, no compression artifacts
- **Content**: Show actual functionality, not mockups

### Naming Convention
```
[feature]-[description].png
Examples:
- main-gui.png
- bluetooth-scanner-devices.png
- settings-security.png
```

### How to Capture
1. Use Flipper Zero hardware when possible
2. For development screenshots, use the emulator
3. Ensure UI is clean and focused
4. Add annotations if needed (use minimal text overlays)
